# v0.1.0-alpha.1 — 通用游戏多 Agent 核心框架

## 版本定位

这是 `muti-agent` 通用游戏制作多 Agent 框架的第一个 Alpha 预发布版本。

当前版本完成了核心架构、协作契约和状态管理规则，已经可以开始真实游戏项目的前向试运行，但尚未经过完整生产闭环验证，不应视为稳定版本。

## 已实现

- 通用核心、默认参考编制和项目专属编制规则；
- 项目经理、项目编制设计 Agent、部门经理及专业执行 Agent 的职责边界；
- Agent 拆分、合并、新增、撤销和人工批准规则；
- 分级授权、例外升级与五个人工审批闸门；
- Pipeline Contract、Loop Contract 和默认 Loop 状态机；
- Loop 中断、复检、恢复、返工、终止和预算规则；
- Loop Registry 的 Snapshot + Event History 契约；
- Registry 事件摘要链、重放、一致性与并发水位校验；
- Godot 项目适配层、垂直切片工作流和可选工具部门；
- Endshift Protocol P0-A 回放校准及自动化闸门判断。

## 验证结果

- 22 项自动测试全部通过；
- 灰盒 Pipeline Contract 示例校验通过；
- Endshift 回放样本准确识别为 `blocked`；
- 自动化结果不会替代人工体验审批；
- 当前 `main` 已同步至 GitHub 远端。

验证命令：

```powershell
python -m unittest discover -s game/game-production-pipeline/tests -p 'test_*.py' -v
python game/game-production-pipeline/scripts/validate_pipeline_contract.py game/game-production-pipeline/contracts/examples/vertical-slice-greybox.yaml
```

## 当前限制

- The Nameless Vessel 前向样本尚未执行；
- 尚未跑通从项目分析到 `GATE-2` 灰盒的完整真实项目闭环；
- Registry 目前只有契约、模板和校验器，尚无实际持久化适配器；
- `game/skills/` 尚未沉淀稳定通用 Skill；
- 当前仅提供 Godot 适配层，尚未验证 Unity 或其他引擎；
- 框架仍可能根据前向试运行结果调整 Agent、Skill 与 Contract 边界。

## 下一阶段

1. 为 The Nameless Vessel 建立项目画像、项目专属编制和第一条 Contract 链；
2. 完成内容设计、Godot 灰盒、独立 QA、人工审批和失败回退；
3. 让前向样本到达可完整试玩的 `GATE-2`；
4. 复盘两个样本中重复出现的方法，决定哪些内容升级为通用 Skill；
5. 根据首个真实 Loop 选择并实现 Registry 持久化适配器。

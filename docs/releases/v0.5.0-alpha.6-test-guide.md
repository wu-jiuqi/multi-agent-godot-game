## 必须覆盖的行为

- 主美先读取 `registry.yaml`，再按项目需求匹配画风方向；未知方向、路径漂移、目录摘要漂移、缺少来源或权利状态时阻断。
- `palette-knife-impasto` 只作为可选方向输入；D0–D4、风格圣经、资产 Contract、QA、引擎基准和交付验收仍必须完成。
- 注册表目录摘要和 Skill 摘要可重复计算；相同输入的两次发布构建字节一致。
- alpha.5 → alpha.6 迁移只更新托管元数据和锁；未知 alpha.5 框架摘要、非托管文件、损坏 managed block 或漂移目标必须 fail closed。
- 历史已发布 alpha.1–alpha.5 版本命中对应白名单迁移入口；不支持的版本没有自动迁移器。
- Windows PowerShell 5.1 以 UTF-8 无 BOM、LF 读取中文文件；PowerShell 7 可用于复核。

## 主美画风方向试运行

1. 在项目需求中写明题材、平台、目标情绪、读图距离、资产类别和避用条件。
2. 让主美读取注册表，列出匹配方向并说明选择理由；选择 `palette-knife-impasto` 时同时读取其 `references/` 文件。
3. 生成方向草案和风格圣经，记录来源、权利状态、参考图和可复现提示词；提交 D2 人类批准。
4. 继续 D3 资产 Contract、QA 和 D4 交付验收。任何方向模块都不直接创建已批准资产。

## 编码与安装检查

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认版本为 `0.5.0-alpha.6`，状态为 `installed, enabled`。已有项目先执行：

~~~powershell
python game/game-production-pipeline/scripts/plan_plugin_migration.py --project-root <项目路径> --plugin-root game/game-production-pipeline
~~~

只有审阅计划摘要并完成独立审批后才可 apply；不要直接编辑 managed block 或 `plugin-lock.yaml`。

# v0.5.0-alpha.1 — 主美方向与跨域视觉生产闭环

`v0.5.0-alpha.1` 新增一个可选、需项目编制批准的主美 Agent，把“给几张参考图”升级为可运行、可返工、可追溯的美术方向系统。它覆盖联网研究、多方向探索、风格圣经、2D/3D/VFX/动画/UI 视觉翻译、Godot 引擎内 benchmark、技术预算、来源许可、生成式 AI 记录和表现验收。

## 研究依据

实现前核对了 GDC 的 [独特美术方向框架](https://www.gdcvault.com/play/1028954/Art-Direction-Summit-Building-a)、[AAA UI 美术指导](https://gdcvault.com/play/1025498/Art-Direction-for-AAA)、[风格化 VFX 美术指导](https://www.gdcvault.com/play/1023999/Art-Directing-VFX-for-Stylized)、Riot 的 [Game Art 教学](https://www.riotgames.com/en/artedu/intro-to-game-art) 与 [协作式创意研发](https://www.riotgames.com/en/r-and-d-office/collaborative-creative-in-r-d)，以及 Godot 官方导入、Theme、3D Import、HLOD 和 GPU 优化文档。权利层参考 SPDX、WIPO 和 U.S. Copyright Office 的公开材料；这些资料是方法依据，不授予复制其中美术作品的权利。

## 核心变更

- 新增 `AGT-ART-DIRECTOR-TEMPLATE` 和可选美术部门模板，明确拥有/不拥有、授权、文件范围、人工判断和独立验收；
- 新增 `$direct-game-art`：重大方向工作先联网研究，主动给出至少三条实质不同的方向和推荐，不把每个审美细节退回项目所有者；
- 新增 `game-production-art-direction/v1` 与 D0–D4：简报、探索、人工选向、引擎基准、生产冻结；
- 为 D0–D4 分别计算 brief、exploration、direction、benchmark、contract 摘要，防止后续证据变化错误抹除历史选择；
- 风格圣经覆盖形状、轮廓、比例、线/边、明度、色彩、材质、灯光、构图、细节、图形、动效、VFX 与 UI 视觉；
- 技术 Profile 覆盖 2D 源/运行格式、色彩/alpha/过滤/mipmap/压缩/atlas，3D 单位/轴/导入/网格/材质/骨骼/LOD/纹理，以及 UI viewport/scale/safe-area/type/token/contrast/localization；
- D3 要求代表性 Godot 预置场景、目标构建、全 required domains、可读性、自动检查和预算实测；D4 才释放批量最终资产生产；
- 权利链区分 owned/licensed/public-domain/reference-only/unknown，并记录生成式 AI provider/model/version/terms/input/human contribution/output disposition；
- Bootstrap 新建 `game-pipeline/art-direction/` 控制面，项目总校验自动发现 Contract revision、阶段摘要和真实 `repo://` 文件；
- `v0.3.0-alpha.1`、`v0.4.0-alpha.2`、`v0.4.0-alpha.3`、`v0.4.0-alpha.4` 白名单项目均有显式、可回退迁移器。

## UI 边界

主美拥有 UI 的视觉签名：Theme/token、字体、图标、形状、材质、色彩、动效和与世界观的跨域一致性。UI Screen/Flow、信息架构、Container/响应布局、焦点、输入和交互逻辑仍是独立 UI workflow 的事实源。本版本为后续 UI workflow 验证保留完整视觉接口，但不宣称 UI workflow 已完成验收。

## 安全与迁移

迁移先 dry-run，再由项目所有者批准精确 `plan_digest`。执行器在 `game-pipeline/.cache/migrations/<plan_digest>/` 保存逐字节备份，只创建缺失 README、更新 `AGENTS.md` managed block、写审批记录并最后更新 `plugin-lock.yaml`。现有美术/资产 Contract、风格圣经、图片、DCC 文件、Godot 场景、UI、组织、Snapshot 和 Event History 保持逐字节不变；未知摘要和计划后漂移 fail closed。禁止只把 `plugin-lock.yaml` 改回旧版本。

## 验收结论

- 代表性 `clockwork-garden` 纵切片通过 D0–D4；
- 失败注入覆盖伪多方案、过期选向、UI 域缺翻译、预算超限、权利未清、禁用 AI 却有记录、repo 摘要漂移和 revision 原地修改；
- 项目 Bootstrap、总校验、旧版本迁移、Godot 映射、文本编码和确定性打包纳入全量回归；
- 当前仍是 Alpha：还需要真实项目验证风格探索质量、多人资产吞吐、真实 DCC/import 链和目标平台预算。

```powershell
codex plugin add game-production-pipeline@personal
codex plugin list
```

预期显示 `installed, enabled`。Windows PowerShell 5.1 读取 UTF-8 无 BOM 中文时使用：

```powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
```

`chcp 65001` 不会改变 Windows PowerShell 5.1 的文件读取默认编码；PowerShell 7 通常采用更安全的 UTF-8 默认值。不要手工覆盖 managed block 或 `plugin-lock.yaml`。

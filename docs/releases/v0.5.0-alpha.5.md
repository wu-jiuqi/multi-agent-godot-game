# v0.5.0-alpha.5 — 共同立项与自主制作

本版让 Agent 主动辅助所有者敲定项目细节，并在明确启动授权后持续制作、自检、有限返工和独立审核。保留初始方向、人类组织授权和外部动作边界。

## 交付内容

- 19 类立项覆盖、建议与备选、可行性实验、联合启动包和 Production Charter。
- generate / automate / takeover / decide 执行模式，固定上下文与模型/工具来源、DAG、lane、写入所有权与 all-join。
- 单写 JSONL 记录、不可变产物快照、幂等追加、真实自检及独立复查、预算分配和中断恢复。
- GATE-2/GATE-3/D4 可在立项委派审核；D4 仍检查权利、QA、引擎基准和精确产物。发布需明确目标/条件/额度及 GATE-4。
- 可选 Agent Preset Tool Binding；内容纳入审批摘要，来源漂移阻止适配器生成。
- alpha.4 及原有支持版本的白名单迁移入口，保留旧授权模式；不自动启动新生产、不扩大权限。

## 验证与限制

最终回归与构建结果记录于同版测试手册。本版仍是 Alpha：脚本和合成项目验证不能证明真实游戏的趣味性、生产质量或无人接管完成率。没有后台常驻调度、宿主工具拦截、密码学身份校验或自动账单采集。实际 Agent 执行与独立判断需要真实证据。

发布提供源码、可复现插件 ZIP、SHA-256 校验文件、发布说明和测试手册。独立 UI/UX Skill 没有变更。已有游戏项目继续按各自锁定版本运行，升级时单独执行显式迁移。

## 编码与安装检查

插件安装来源需要先指向本版；源码更新不会自动替换 Codex 当前加载的缓存：

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认实际版本与 installed, enabled 状态。已有项目先迁移 dry-run；审批只针对审阅过的摘要。不要直接改 managed block 或 plugin-lock.yaml 来绕过迁移。

Windows PowerShell 5.1 读取中文 UTF-8 无 BOM 文件：

~~~powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
~~~

chcp 65001 不改变旧 PowerShell 的默认文件编码；可用 PowerShell 7 复核。源码和 ZIP 文本统一 UTF-8 无 BOM、LF。

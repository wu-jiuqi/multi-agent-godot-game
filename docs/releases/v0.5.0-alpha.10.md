# v0.5.0-alpha.10

## 主题

把 Godot UI 工作从“装饰组件生成”升级为以真实标杆页面为中心的制作、反馈与验收流程。

## 本版变更

- 增加任务定义、信息层级、操作路径和恢复路径作为 UI 实现前置产物。
- 明确区分组件实验场与真实使用页面；实验场不能单独证明成品质量。
- 在完整页面前增加静态目标稿、最终尺寸小样和素材使用约定。
- 将真实运行截图与交互录制纳入证据，功能、视觉、动效/导出三类结论独立记录。
- 明确 Godot 4.7.1 `offset_transform_*` 的视觉变换与输入区域策略，分开验证 `button_down`、`button_up`、`pressed` 和业务成功反馈。
- 取消对 `Button`、`Panel`、`Label` 等原生语义控件的机械禁用；要求通过 Theme、状态矩阵和交互证据完成主题化。
- 保留预置 Control/Container 场景优先、双契约边界、资产 Manifest、reduced-motion 和失败回退路由。

## 迁移

新增从 `v0.5.0-alpha.9` 到本版的受摘要保护迁移器，并保留从历史 alpha 版本到本版的直接迁移入口。迁移只更新插件托管元数据，不改写项目已有场景、资源、UI、Event History 或业务事实；未知框架摘要继续 fail closed。

## 安装

插件与独立 UI Skill 分开安装；插件 ZIP 不会自动安装独立 Skill。更新 Personal Marketplace 源后执行：

```powershell
codex plugin add game-production-pipeline@personal
codex plugin list
```

确认版本为 `0.5.0-alpha.10` 且状态为 `installed, enabled`。独立 Skill 解包到 `C:\Users\30114\.codex\skills\ui-ux-pro-max`，再回读 `SKILL.md` 与 `references/godot-production.md`。重装后需新建 Codex 会话才能加载新版 Skill。

Windows PowerShell 5.1：`Get-Content -LiteralPath "文件路径" -Encoding UTF8`；执行 `chcp 65001`，并使用 PowerShell 7 复核。

迁移必须保留 managed block 和 `plugin-lock.yaml`，不能手工改锁文件绕过审批。

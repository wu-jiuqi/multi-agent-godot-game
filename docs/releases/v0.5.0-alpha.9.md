# v0.5.0-alpha.9 — Godot UI 生产 Agent 执行契约

本版把 Godot UI 生产提示词落成可复用的 Agent、Workflow 和 Skill 参考，补齐从输入检查到目标构建证据的执行边界，同时保留 UI/UX 与主美的双契约职责分离。

## 交付内容

- 新增 `agents/ui-production.md`，定义 Godot UI 生产 Agent 的职责、四级任务模式、输入门禁、资产 Manifest、组件 API、Motion Token、证据要求、固定十段输出和人工判断边界。
- 新增 `workflows/ui-production.md`，把 `prototype`、`greybox`、`style-pass`、`final` 映射为可复核的准入、产出、自动验证、人工验收、退出条件和失败回退。
- 扩展顶层 `skills/ui-ux-pro-max` 的 Godot production mode，并新增 `references/godot-production.md`，覆盖预置节点、`.tscn`/`.tres` 序列化、状态矩阵、reduced-motion、响应式、本地化、RTL、可访问性、资源替换、性能和截图证据。
- 增加文档回归测试，防止 Godot UI 入口、双契约边界和四类回退路由漂移。
- 为 alpha.1–alpha.8 保留到本版的显式迁移入口，并新增 alpha.8 → alpha.9 的摘要白名单迁移。

## 验证与限制

- 自动验证检查文档入口、迁移、编码和结构证据；它不能代替真实 Godot 项目的目标构建、主美视觉验收或人工 Gate。
- `final` 仍要求当前 UI Screen/Flow Contract、UI Visual Contract、目标构建截图/录屏和人工视觉审查；缺少视觉契约只能停在 `prototype`、`greybox` 或待人类批准的风格提案。
- 本版仍是 Alpha，尚未宣称任意游戏项目达到商业 UI 完成标准。

## 安装与迁移

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认版本为 `0.5.0-alpha.9` 且状态为 `installed, enabled`。已有项目先读取本版发布包和迁移计划，审阅完整动作与精确摘要，再按项目所有者批准的迁移计划执行；不要直接改 managed block 或 `plugin-lock.yaml`。

Windows PowerShell 5.1 读取中文 UTF-8 无 BOM 文件时使用：

~~~powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
chcp 65001
~~~

`chcp 65001` 不会改变旧 PowerShell 的默认文件编码；PowerShell 7 可用于复核。迁移时保留 managed block 和 `plugin-lock.yaml`，不要直接覆盖它们。

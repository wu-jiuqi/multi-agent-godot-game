# v0.5.0-alpha.6 — 主美画风方向注册表与可选模块

本版把主美可用的画风方向整理为机器可读注册表，并接入一个可选的刮刀厚涂油画方向模块。主美先读取方向列表，再依据项目需求、标签、适用范围和避用条件选择方向；选择后仍必须完成 D0–D4 的人类来源、权利、QA、引擎基准和交付验收。

## 交付内容

- `direct-game-art/style-directions/registry.yaml`：主美画风方向注册表，记录方向 ID、模块路径、来源、摘要、标签、适用范围、避用条件和目录摘要。
- `palette-knife-impasto`：同步的可选画风模块，保留风格圣经、输入与提示词规范、Mindrift profile，并明确只提供参考方向，不自动改变主美审批边界。
- 主美路由规则：读取注册表后选择模块；未知 ID、路径漂移、摘要漂移、来源或权利状态不完整时停止并请求处理。
- 注册表校验器与回归测试：校验 schema、ID、路径、Skill 文件、来源 URI、权利状态、目录摘要和注册表完整性摘要。
- `v0.5.0-alpha.5 → v0.5.0-alpha.6` 显式元数据迁移；同时保留历史已发布版本到 alpha.6 的白名单直达入口。迁移会更新托管元数据和锁，不覆盖用户资产、风格圣经或项目历史。

## 验证与限制

本版仍是 Alpha。注册表和模块选择流程已通过合成项目、失败注入和完整回归，但真实项目中的风格探索质量、资产吞吐、平台基准和无人接管完成率仍需验证。画风模块不会代替 D2 风格圣经批准、D3 资产 Contract 或 D4 交付验收。

发布包含可复现插件 ZIP、SHA-256 校验文件、发布说明和测试手册。GitHub Release 为 Pre-release，不设置为 latest。

## 编码与安装检查

插件安装来源需要先指向本版；源码更新不会自动替换 Codex 当前加载的缓存：

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认版本为 `0.5.0-alpha.6` 且状态为 `installed, enabled`。已有游戏项目先执行迁移 dry-run，再由人类审批摘要；不要直接改 managed block 或 `plugin-lock.yaml` 绕过迁移。

Windows PowerShell 5.1 读取中文 UTF-8 无 BOM 文件：

~~~powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
~~~

`chcp 65001` 不改变旧 PowerShell 的默认文件编码；可用 PowerShell 7 复核。源码和 ZIP 文本统一 UTF-8 无 BOM、LF。

## UI 工作流检查

- 页面先写任务定义、信息优先级和操作路径，再写视觉目标与最终尺寸小样。
- 组件实验场与真实使用页面分开，后者必须有真实运行截图。
- 素材 Manifest 或使用约定包含用途、显示尺寸、透明区、文字安全区、拉伸区、固定装饰、来源许可和状态。
- 标杆页面覆盖 normal、hover、focus、pressed、selected、disabled、error，并区分按压反馈、有效激活和业务结果。
- Godot 4.7.1 记录 `offset_transform_visual_only`，测试快速进出、拖出取消、键盘导航、动画中禁用、反复开关和窗口尺寸变化。
- `functional`、`visual`、`motion_export` 三类验收分别有证据；缺失项标为 `review_pending` 或 `blocked`。

## 编码和安装

源码和 ZIP 内文本必须为 UTF-8 无 BOM、LF。Windows PowerShell 5.1 读取中文文件时使用：

```powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
chcp 65001
```

PowerShell 7 可用于复核。更新 Personal Marketplace 源后确认 `codex plugin list` 为 `0.5.0-alpha.10`、`installed, enabled`；独立 UI Skill 需单独解包。

```powershell
codex plugin add game-production-pipeline@personal
codex plugin list
```

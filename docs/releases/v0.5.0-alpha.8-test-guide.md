# v0.5.0-alpha.8 测试手册

## 回归命令

从仓库根目录运行：

~~~powershell
python -m pytest -q game/game-production-pipeline/tests
python game/game-production-pipeline/scripts/validate_art_direction_contract.py <项目>/game-pipeline/art-direction/ui-visual-contract.yaml --project-root <项目>
python game/game-production-pipeline/scripts/build_release.py --plugin-root game/game-production-pipeline --output-dir dist
~~~

预期结果：管线回归通过；独立 UI Visual Contract 状态为 `valid`；发布构建状态为 `built`，生成 ZIP 与 `.sha256`。

## 必须覆盖的行为

- UI required domain 缺少 UI Visual Contract、Style Frame、字体、图标、六态状态矩阵或 Theme 映射时 D3 失败。
- UI Visual Contract 的 digest 变化会使相关 benchmark/review 失效；视觉问题路由 `UI_VISUAL`，结构问题路由 `UI_STRUCTURE`，技术问题路由 `UI_TECH`，可读性问题路由 `UI_READABILITY`。
- 不包含 UI 的项目保持原有 Art Direction 校验，不被错误要求 UI Visual Contract。
- alpha.1–alpha.7 项目均必须命中对应的显式迁移入口；未知摘要必须阻断且不写入项目。
- 自动检查只判断 schema、路径、摘要和证据存在性；主美仍需要确认视觉签名、跨屏一致性和目标构建美感。
- Godot UI 使用预置 Control/Container/PanelContainer/Button/HSlider/ProgressBar 节点；脚本只连接交互和动效，不动态生成整套 UI。

## 安装与迁移

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认版本为 `0.5.0-alpha.8`，状态为 `installed, enabled`。项目更新前保存当前 `plugin-lock.yaml` 和审批准入记录，阅读本版摘要后再执行项目迁移。

## Windows 编码

Windows PowerShell 5.1 的项目迁移必须保留 `managed block` 和 `plugin-lock.yaml`，再使用下面命令读取文件：

~~~powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
chcp 65001
~~~

PowerShell 7 可用于复核。源码和 ZIP 文本必须保持 UTF-8 无 BOM、LF。

`chcp 65001` 只切换控制台代码页，不会改变旧 PowerShell 的默认文件编码。

## 必须覆盖的行为

- Godot UI 任务选择且只能选择 `prototype`、`greybox`、`style-pass`、`final` 之一；缺少会改变方向的输入时集中提问不超过五个问题。
- UI/UX 的 Screen/Flow 与主美的 UI Visual Contract 保持独立；视觉契约缺失时只能灰盒或待人类批准的风格提案。
- 固定 UI 使用编辑器预置 Control/Container 节点并序列化到 `.tscn`/`.tres`；运行时只实例化已有 PackedScene，不重建固定树。
- 资产 Manifest 记录 source/runtime URI、状态、尺寸、九宫格、导入、压缩/过滤、授权、fallback、owner 和 version/digest。
- 组件覆盖 normal、hover、pressed、focus、disabled、error，按需增加 loading/selected/success/empty；Motion Token、reduced-motion、质量降级和静态 fallback 可追踪。
- 验证覆盖场景、声明的输入设备、响应式、长文本/CJK/RTL、可访问性、资源替换、性能和目标构建截图；验收状态只允许 `greybox`、`implementation_ready`、`review_pending`、`approved`、`blocked`。
- `UI_VISUAL`、`UI_STRUCTURE`、`UI_TECH`、`UI_READABILITY` 回退路径保持明确；自动检查不代替人工视觉质量判断。
- alpha.1–alpha.8 项目都能找到到 alpha.9 的显式迁移器；未知框架摘要仍 fail closed。

## 安装与迁移

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认版本为 `0.5.0-alpha.9`，状态为 `installed, enabled`。项目更新前备份 `plugin-lock.yaml` 和审批记录，先执行 dry-run、审阅迁移计划摘要和动作，再由项目所有者批准应用。

迁移必须保留 managed block 和 `plugin-lock.yaml`，不能用手工改锁文件绕过审批。

## 编码

源码和发布 ZIP 内文本必须是 UTF-8 无 BOM、LF。Windows PowerShell 5.1 读取中文文件时使用：

~~~powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
chcp 65001
~~~

`chcp 65001` 不会改变旧 PowerShell 的默认文件编码；PowerShell 7 可用于复核。

## 运行态完整模式

```powershell
python game/game-production-pipeline/scripts/validate_loop_registry.py `
  --snapshot <project>/game-pipeline/loops/registry/<loop>/snapshot.yaml `
  --history <project>/game-pipeline/loops/registry/<loop>/event-history.yaml `
  --record-template game/game-production-pipeline/contracts/loop-registry-record.template.yaml `
  --event game/game-production-pipeline/contracts/loop-registry-event.template.yaml `
  --contract <project>/game-pipeline/loops/contracts/<contract>.yaml `
  --state-machine game/game-production-pipeline/contracts/loop-state-machine.default.yaml
```

合法历史必须退出 0。分别复制输入到临时目录，再破坏事件 `event_digest`、`concurrency.expected_record_revision` 或 Snapshot `last_event_sequence`，三次命令都必须退出非 0；不得改写项目权威历史。

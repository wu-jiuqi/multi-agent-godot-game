# v0.5.0-alpha.7 — UI Visual Contract 与主美验收链路

本版补齐“主美视觉方向 → UI Visual Contract → UI 视觉资源 → Godot 实现 → 主美视觉验收”的生产链路。UI/UX 继续负责信息架构、Screen/Flow、布局和交互；主美负责 UI 的视觉身份与视觉验收。

## 交付内容

- 新增 `contracts/ui-visual-contract.template.yaml`，登记形状语言、材质、颜色 Token、字体、图标、装饰、六态组件矩阵、动效语气、Theme/Style Frame、benchmark、所有权和返工路由。
- 新增独立 UI Visual Contract 校验与 `UI_VISUAL`、`UI_STRUCTURE`、`UI_TECH`、`UI_READABILITY` 返工路由。
- D3/D4 在 `required_domains` 包含 `ui` 时验证 UI Contract、摘要绑定、关键屏幕 Style Frame、字体、图标、状态矩阵、Theme 映射、benchmark、主美评审和目标构建证据；自动校验只判断结构和证据存在性。
- 更新主美、Art Department、UI Visual workflow 和 Godot adapter：默认 `StyleBoxFlat`、单线边框和无视觉资产控件只能作为灰盒；最终 UI 必须消费批准的视觉交付物。
- Atelier Demo 补齐组件形状、字体、图标、装饰和状态变体，并保留预置 Control/Container/PanelContainer/Button/HSlider/ProgressBar 结构。

## 验证与限制

本版仍是 Alpha。自动验证不能判断审美质量、视觉层级是否真正符合主美意图，仍需要主美对 Style Frame 和目标构建截图/视频进行人工评审。

## 编码与安装检查

~~~powershell
codex plugin add game-production-pipeline@personal
codex plugin list
~~~

确认版本为 `0.5.0-alpha.7` 且状态为 `installed, enabled`。已有项目应先读取本版发布包和摘要，再按项目迁移流程更新托管元数据；不要直接改 managed block 或 `plugin-lock.yaml` 绕过审批。

Windows PowerShell 5.1 读取中文 UTF-8 无 BOM 文件：

~~~powershell
Get-Content -LiteralPath "文件路径" -Encoding UTF8
~~~

`chcp 65001` 不改变旧 PowerShell 的默认文件编码；可用 PowerShell 7 复核。源码和 ZIP 文本统一 UTF-8 无 BOM、LF。

## 本次验证结果

- 管线完整回归：209 项测试通过。
- UI Visual Contract 缺少 Contract、Style Frame、字体、图标、状态矩阵或 Theme 映射时 D3 失败；摘要变化会使 benchmark/review 失效；非 UI 项目不被强制要求 UI Contract。
- 插件源码与发布 ZIP 通过 UTF-8 无 BOM、LF 校验；发布 ZIP 与 SHA-256 sidecar 由构建脚本生成。
- Atelier Demo 通过 standalone UI Visual Contract 校验、Godot headless 启动和 1280×720、1920×1080、2560×1080 启动检查；目标构建的视觉审美仍需主美人工签字。

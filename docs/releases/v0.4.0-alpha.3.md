# v0.4.0-alpha.3 — Loop Registry 运行态 CLI 修复

`v0.4.0-alpha.3` 修复 `validate_loop_registry.py` 在提供 `--history` 后仍先把 active Snapshot 当作 draft 注册模板校验的缺陷。旧实现因此固定误报初始状态、iteration、水位、空资源和示例 ID 六类错误；历史重放本身可以为零错误。

## 变更

- 无 `--history`：保持原 draft 模板校验命令和语义；
- 有 `--history`：切换为运行态模式，active Snapshot 不再进入 draft 规则；
- 新增 `--record-template`，允许运行态完整命令独立校验官方 draft Record Template；
- 静态检查覆盖 Event/Payload Contract、Loop Contract、状态机和转换绑定；
- 运行态检查覆盖事件摘要重算、`previous_event_digest`、`sequence`、`mutation_id`、`record_revision`、状态/iteration 重放、Snapshot 尾水位、绑定和资源 ID；
- 新增 `v0.4.0-alpha.2→v0.4.0-alpha.3` 显式迁移器，只更新 `AGENTS.md` managed block、审批记录和 `plugin-lock.yaml`，并验证 Event History 摘要保持不变；
- 保留从已发行 `v0.3.0-alpha.1` 直接迁移到当前候选版的受控路径。

## 兼容性

原模板命令完全兼容。alpha.2 的 `--snapshot ... --history ...` 命令也继续可用，并自动获得修复后的运行态语义；新增的 `--record-template` 是推荐的完整校验输入。没有错误白名单、强制成功、阈值放宽或历史数据改写。


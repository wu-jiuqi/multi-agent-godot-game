# v0.5.0-alpha.1 测试与发布验收手册

## 全量回归与构建

```powershell
python -m unittest discover -s game/game-production-pipeline/tests -p 'test_*.py' -v
python game/game-production-pipeline/scripts/validate_text_encoding.py --plugin-root game/game-production-pipeline

```

重复构建两次，ZIP SHA-256 必须相同。发布 ZIP 中不得包含 `__pycache__`、`.pyc`、临时文件或工作区密钥。

## D0–D4 纵切片

```powershell
python game/game-production-pipeline/scripts/validate_art_direction_contract.py `
  game/game-production-pipeline/contracts/examples/art-direction-clockwork-garden.yaml `
  --gate D4

python game/game-production-pipeline/scripts/evaluate_art_direction_gate.py `
  game/game-production-pipeline/contracts/examples/art-direction-clockwork-garden.yaml `
  --gate D4
```

预期分别返回 `state=valid` 和 `state=pass`，后者始终有 `writes_performed=false`。将 `direction_approval` 改成 pending，D2 应返回 `awaiting_human`；改变 selected option 而不更新审批应阻断为 stale/mismatch。

## 探索与风格系统失败注入

- 研究少于三项、没有 primary/video、没有非游戏影响或 anti-copy：D1 非 0；
- 三个候选使用相同 signature：D1 非 0，防止把 palette swap 冒充多方向；
- required_domains 包含 UI 但缺少 translation mapping 或 UI Profile：D3 非 0；
- 任一视觉语言缺 rule/avoid、风格支柱少于 3 项或没有受控变量：D3 非 0；
- 改 benchmark capture 后，direction digest 保持不变，benchmark/contract digest 必须变化。

## Godot benchmark 与预算

真实项目的 D3 需要编辑器可打开的预置 `.tscn` benchmark、实际 Theme/Material/Environment 资源、目标 renderer/camera/build、可读性捕获和 profiler 数据。按 Contract 破坏 texture memory、draw call、transparent overdraw、mesh/material、VFX、UI batch/font atlas 或 frame-time 中适用的一项，Gate 必须返回 `revise`。

`.import` 可以作为导入配方证据；`.godot/imported/` 只能是 cache。不得用离线渲染或编辑器预览代替目标构建。

## 权利与生成式 AI

- D0 可接受 `conditional`，D4 必须 `cleared`；
- reference register 与 release clearance 缺失时 D4 阻断；
- 需要署名却没有 manifest 时 D4 阻断；
- `generative_ai_policy=forbidden` 却存在 AI record 时结构校验失败；
- 允许的 AI record 缺 provider/model/version/terms/human contribution/output disposition 时失败。

这只是记录和流程验证，不替代适用司法辖区的专业法律意见。

## 项目总校验与 UI 只读

```powershell
$before = Get-FileHash -Algorithm SHA256 <project>/game/scenes/ui/screen-flow.tscn
python game/game-production-pipeline/scripts/validate_project_instance.py --project-root <project>
$after = Get-FileHash -Algorithm SHA256 <project>/game/scenes/ui/screen-flow.tscn
$before.Hash -eq $after.Hash
```

结果必须为 `normal` 和 `True`。主美 Contract 可以引用 UI 视觉 token，但不能直接修改 UI Screen/Flow、布局行为或交互事实源；结构变化必须留给后续独立 UI workflow。

# 刮刀厚涂油画风格规范

本规范是缺少用户细节时使用的默认值。用户提供的文字、色卡和参考图可以覆盖对应部分；不得为保留默认色调而改写用户的主体、情绪或构图。它不限定人物、故事、时代、题材或象征物。

## 材质与笔触

- **颜料有厚度：**表现堆积、覆盖和刮开的油彩，厚颜料边缘产生与画面光源一致的微小高光和阴影。避免只有平面纹理贴图的效果。
- **刮刀有刀面：**用宽阔、有方向的色块塑造大体积；刀锋留下断续边缘、局部拖痕和少量脊线。刀痕服从物体结构和构图节奏。
- **画布有呼吸：**粗画布仅在薄涂区、刮开处和少量边缘露出。厚涂区应遮住底布，不给全画面叠加同样强度的颗粒。
- **细节有取舍：**先保证轮廓、体块、空间关系可读，再把少量精细笔触集中在主体。远景和次要区域可以合并为较大色面。
- **材质有区别：**木材、陶器、织物、皮肤和金属仍保持各自可辨的结构与反光；不要把所有物体处理成相同的结块表面。

用户仅提供色卡时，以上材质语言保持默认。用户明确要求改变笔触密度、画布显露程度或写实程度时，按其要求调整。参考图只在被指定的用途内影响结果，不自动复制其主体。

## 色彩与光照

默认色彩家族为奶油白、灰粉、旧黄、暗酒红与深蓝；它们是可替换的语言描述，不是从项目图片精确采样所得的色值。

| 作用 | 默认处理 | 用户提供色卡时 |
|---|---|---|
| 大面积基调 | 奶油白、灰粉或旧黄中的少数颜色 | 从用户颜色中选择主导色，不要求使用全部颜色 |
| 暗部与空间深度 | 深蓝、暗酒红及低明度混色 | 用指定暗色或主色的较暗层次，保留结构辨识度 |
| 视觉重点 | 小面积暖色、较亮色或局部饱和色 | 按用户主次说明配置；未说明时限制强调色面积 |
| 冷暖关系 | 暖光与较冷阴影，或相反的明确选择 | 跟随用户情绪与参考光线，不强制冷暖各占一半 |

先建立清楚的明暗分组，再加入色温变化。不要用“厚涂”作为过度饱和、全画面高对比或不自然反光的理由。保留混色产生的微小偏色，但不承诺生成结果逐像素匹配 HEX/RGB。

## 构图与用途

- 根据用户给定的主体、镜头、比例和用途构图；未指定时选能清晰展示主体的简单构图。
- 背景、主体、强调处的笔触密度形成层次；避免每个角落同等锐利、同等繁杂。
- 需要叠加界面或文字时，按需求在指定区域预留低对比、少细节的空间；不要无理由为所有图片留空。
- 单个道具强调清晰轮廓与材质识别；场景强调空间与焦点；人物强调姿态、五官结构和服饰关系。都不预设特定人物或故事。
- 图片编辑以用户要求保留的区域、身份、构图或轮廓为约束；换画风不等于重新设计主体。

## 可直接拼入提示词的材质段

> 刮刀厚涂油画，具有真实体积感的厚油彩堆积，宽阔刀面色块和断续刀锋边缘，沿物体体积组织笔触；粗画布只在薄涂和刮开处选择性露出。明暗分组明确，冷暖关系服从光源，主体附近细节集中，次要区域笔触概括。避免全画面均匀颗粒、滤镜式油画纹理和相同密度的噪点。

该段只描述媒介和成像目标。主体、颜色、情绪、比例、参考图角色和编辑保留项须从本次输入补充，不把历史项目题材附加进去。

## 结果检查

1. 用户指定的主体、色彩关系与构图是否成立？
2. 能否看出厚油彩、刀面与底布之间的差别？
3. 刀痕是否塑造体积，画布是否只在合理位置露出？
4. 是否有清晰焦点，而非全画面同等噪杂？
5. 编辑任务中要求保留的内容是否保持？

检查以实际看到的生成结果为准。无法查看结果时不声称已通过；发现偏差时描述具体偏差，再按用户当前任务范围决定是否迭代。
